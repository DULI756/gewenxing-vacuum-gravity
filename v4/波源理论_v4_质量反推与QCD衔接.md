## 3. 力平衡：两口径并列与推荐

v3 建立质子内尺度三力平衡 330 = 266 + 64 N（静电斥力 = 磁箍 + 引力），τ_b/τ_i = 0.554/0.446 为比值结构。f₀ 变化后，力标度与 σ 的关系需要重新裁定。两口径并列如下（数值均经复核）：

### 口径 A：σ 固定（1.14×10⁻³¹ m²，√σ = 0.338 fm）

$$F_e = \frac{R_0\,\sigma}{d^2} = 132.7\ {\rm N}, \qquad F_g = \frac{G_0\,\sigma}{d^2} = 106.8\ {\rm N}, \qquad F_{\rm mag} = F_e - F_g = 25.9 \approx 26\ {\rm N}$$

即 **132.7 = 106.8 + 25.9**。比值结构保留（F_g/F_e = τ_i/τ_b = 1.242）；绝对标度较 v3 降 59.8%（∝ f₀⁴：0.403）。

### 口径 B：保持 330 = 266 + 64，σ 重标

$$\sigma' = \frac{330\,d^2}{R_0} = 2.836\times10^{-31}\ {\rm m}^2 \qquad (\sqrt{\sigma'} = 0.533\ {\rm fm})$$

校验：F_e' = 330.0 N、F_g' = 265.7 ≈ 266 N、F_mag' = 64.3 ≈ 64 N ✓。

### 推荐：口径 B（保持三力平衡 330 = 266 + 64）

理由：
1. **σ 在 v3 中本身是由三力平衡反解出的参数**（σ = 330·d²/R₀），不是独立锚点；频率与几何变化后按同一条反解链重导 σ' = 2.836×10⁻³¹ m²，是框架内自洽的延续。
2. **330 = 266 + 64 是 v3 的物理断言**（质子内尺度电荷斥力 = 磁箍 + 引力）。两口径的比值结构 τ_b/τ_i = 1.242 相同，差异只在绝对标度；口径 A 使该标度无框架内理由地塌缩 60%。
3. **几何相容**：√σ' = 0.533 fm < 源间距 s = 0.5993 fm < 质量层 R_m = 0.670 fm——相互作用截面尺度落在源几何内。

**决策规则（诚实）**：若未来 σ 由 ch13 散射数据独立锚定（当前 σ 与 ch13 反解存在 3–4 倍差异，开放项，§5-5），则应转用口径 A 的绝对标度。两口径的比值结构相同，分歧仅限绝对标度。

## 4. QCD 衔接（真实文献对照，不宣称替代）

### 4.1 QCD 质量起源四要素（真实、已核验）

1. **手征对称自发破缺**：夸克凝聚 ⟨ψ̄ψ⟩ ≠ 0。格点值 ⟨ψ̄ψ⟩_MS̄(μ=2 GeV) = −0.0147(8)(16)(12) GeV³ = −[245(4)(9)(7) MeV]³（Giusti et al. 1999, Nucl. Phys. B 538, 249）；公认量级约 −(230–280 MeV)³。手征破缺把 ~2–5 MeV 的流夸克质量"放大"为 ~300 MeV 组分夸克质量。
2. **流夸克质量**（PDG 2024，MS̄，μ = 2 GeV）：m_u = 2.20(4)(6) MeV、m_d = 4.69(3)(4) MeV、m_s = 92.74(22)(49) MeV。
3. **场能**：夸克动能/势能 + 胶子场能。
4. **trace anomaly**：QCD 能动量张量迹的量子反常（胶子凝聚 ⟨G²⟩）对质子质量的贡献。

**Ji 质量分解**（Ji 1995, PRL 74, 1071；配套长文 PRD 52, 271；格点数值 Yang et al. 2018, PRL 121, 212001，MS̄，μ=2 GeV）：

| 分解项 | 占质子质量比例 |
|---|---|
| 夸克能量项（H_E） | 33(4)(4)% |
| 胶子场能项（H_g） | 37(5)(4)% |
| ¼ trace anomaly（H_a） | 23(1)(1)% |
| u/d/s 标量凝聚项（H_m，含流质量） | 9(2)(1)% |

即：**场能 + 反常占 ~91%，显式夸克质量/标量凝聚项仅 ~9%**。

### 4.3 机制差异与硬伤（必须诚实标注）

1. **无手征机制**：波源框架没有手征对称性概念。"组分夸克 ~300 MeV ↔ 流夸克 ~2–5 MeV"的放大机制（手征破缺）在波源框架中无对应；μ = 1.29333 MeV 是 n−p 锚定，不是手征机制产物。**硬伤。**
2. **无规范场/胶子**：没有禁闭势、渐近自由与 trace anomaly。"场能主导"只是定性同构，生成机制完全不同。**硬伤。**
3. **奇异重子不可推广**：m = m_c + μN 无法推广到 Λ/Σ/Ξ/Ω（s 夸克无波源数）——v3 已有硬伤，v4 未解决。**硬伤。**
4. **μ 是锚定非第一性原理**；η = 1/409.3 随 f₀ 变化，无独立来源。**开放。**
5. **m_c 与能量层几何脱钩**（比值 1.2549 无机制推导，§2.4）。**开放（v4 新增）。**
6. **波源数 10/11、u=3/d=4** 是构造反解，无独立预言能力。

**诚实结论**：v4 是能复现 p/n 质量、n−p 质量差与质子电荷半径的**锚定型拟合框架**，与 QCD 质量起源存在定性同构（场能主导、电荷/质量双标度），但机制不同，**不构成对 QCD 质量起源的替代解释**。

### 4.4 双标度：电荷半径 vs 质量半径（真实数据对照）

- 电荷半径：r_p = 0.8409(4) fm（PDG 2024）；渺子氢测量 r_E = 0.84087(39) fm（Antognini et al. 2013, Science 339, 417）。
- 质量半径（方法间存在争议，如实注明）：

  - 格点 QCD 味分解引力形状因子：约 0.63–0.70 fm（如 arXiv:2310.08484；arXiv:2502.16689 报 0.697(37) fm）。
